## Funcionalidades

- Registrar libro
- Buscar libro
- Listar libros
- Contar libros
- Menú de consola

---

## Instrucciones de ejecución

**Requisitos**
- Java JDK 8 o superior
- IntelliJ IDEA

**Pasos**

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/JuanPabloMezaOlivera/biblioteca-personal.git
   ```
2. Abrir el proyecto en IntelliJ IDEA: `File` → `Open` → seleccionar la carpeta del proyecto
3. Ejecutar la clase principal desde IntelliJ
4. Interactuar con el sistema desde la consola

## Flujo colaborativo

**Reglas aplicadas sobre la rama main**

- Commits directos bloqueados
